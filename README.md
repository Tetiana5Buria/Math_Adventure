# Math Adventure — Space Mission

An interactive educational math game for children aged 7–8, built with **HTML, CSS, and Vanilla JavaScript**.

Players become space explorers, solve math problems, collect points, and help a rocket travel toward a planet.

## About the Game

Math Adventure is a browser-based game designed to make learning mathematics fun and engaging.

Children can choose their difficulty level and practice addition and subtraction through interactive challenges.

The game is designed for second-grade students and includes 60 math questions divided into three difficulty levels.

## 🌍 Difficulty Levels

| Level  | Planet     | Math Challenges                                               |
| ------ | ---------- | ------------------------------------------------------------- |
| Easy   | 🌍 Earth   | Addition and subtraction up to 20                             |
| Medium | 🪐 Mars    | Addition and subtraction up to 100, mostly without regrouping |
| Hard   | 🚀 Jupiter | Addition and subtraction up to 100, including regrouping      |

Each mission consists of 10 randomly selected questions.

## ✨ Features

- Three difficulty levels
- Multiple-choice math questions
- Random question selection
- Immediate feedback for correct and incorrect answers
- Score tracking
- Animated rocket and space-themed interface
- Mission progress bar
- Final results screen
- Restart functionality
- Responsive design for desktop and mobile devices

## 🛠 Technologies

- **HTML5** — Semantic page structure
- **CSS3** — Responsive layout, custom properties, gradients, and animations
- **JavaScript (ES6+)** — Game logic and DOM manipulation
- **JavaScript Modules** — Separation of game logic and question data

No frontend frameworks or additional JavaScript libraries are required.
